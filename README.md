PROYECTO BACKEND ACADÉMICO - UNIVERSIDAD DE REMINGTON 2026
📋 Descripción del Proyecto
Backend Académico es una aplicación Java desarrollada como proyecto fin de carrera en la Universidad de Remington. Este sistema está diseñado para gestionar y administrar los procesos académicos de la institución educativa.

🎯 Objetivos
Proporcionar una API robusta para la gestión de procesos académicos
Facilitar la administración de estudiantes, docentes y cursos.
Automatizar procesos académicos clave
Garantizar la seguridad e integridad de los datos
